# ZK Passport on Gnosis Chain

The ZK Passport registry runs natively on <OutLink href="https://www.gnosis.io">Gnosis Chain</OutLink> (chain ID `100`) with its own `StateKeeper`, Sparse Merkle Trees and `Registration2`. Contracts that verify query proofs on Gnosis read the registration root directly, so no [cross-chain replication](/zk-passport/guide-setting-up-cross-chain-replication) is needed.

The deployment supports every document type registered on Rarimo L2, and adds the [`NoAARecovery`](/zk-passport/contracts#noaarecovery) module for documents without Active Authentication. See the [smart contracts reference](/zk-passport/contracts) for the interfaces.

:::info
Registration and query proofs must be generated with the circuits the verifiers were built from:

- Register proofs: <OutLink href="https://github.com/rarimo/passport-zk-circuits-noir/releases/tag/v0.2.7">passport-zk-circuits-noir v0.2.7</OutLink> (SHA-256 full-modulus certificate leaf);
- Query proofs: <OutLink href="https://github.com/rarimo/passport-zk-circuits-noir/releases/tag/v0.2.6">passport-zk-circuits-noir v0.2.6</OutLink> (`query_identity`, `query_identity_td1`).

Proofs from older circuit releases are rejected.
:::

## Register verifiers

Verify the register proof of a document type. A circuit name encodes the document parameters:

`<signature type>_<hash size>_<document type>_<encapsulated content chunks>_<encapsulated content shift>_<DG1 shift>_<AA>`
